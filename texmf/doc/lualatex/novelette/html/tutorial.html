Overview

You will partition your text into a single main document file, containing all global settings in its Preamble, and a number of sub-document files. The sub-documents may be as short as one page, or as long as a chapter (or more). After its Preamble, the body of the main document will call the sub-documents in order, to create the whole book. Sub-documents may contain other sub-documents.

You may compile an individual sub-document. It will read settings from the main document Preamble, then typeset its own content, with the content of its own sub-documents.

Instead of a hierarchical structure of chapters and sections, Novelette regards all content areas as components with no particular purpose; their meanings are determined by what you write. A component may be as short as one page (such as the title page), or very long (one or more chapters). You decide.

 

File and Folder Structure

TOP

All content must be kept in a single main folder, which has the main document.

  • You may use sub-folders for the various sub-documents and images, but they do not need to be in hierarchical order, because every path is relative to the main document.

  • No content may be included, unless it is within the same folder as the main document, or in a subfolder beneath the main document. This restriction ensures that when you copy or archive the folder containing the main document, you will have all content.

  • A typical folder structure looks like this:

    MurderAtWhereville (main folder)
|- murder-at-whereville.tex (main document)
|- subdocs (folder)
   |- frontmatter (folder}
      |- title-copyright.tex (subdoc)
      |- epigraph.tex (subdoc)
   |- early-material (folder)
      |- history.tex (subdoc, chapter 1)
      |- family.tex (subdoc, chapter 2)
   |- crime-scene (folder)
      |- discovery.tex (subdoc, subdoc, chapter 3)
      |- investigation.tex (subdoc, chapter 4)
   |- suspects (folder)
      |- tom.tex (subdoc, chapter 5)
      |- dick.tex (subdoc, chapter 6)
      |- harry.tex (subdoc, chapter 7)
   |- solution (folder)
      |- evidence.tex (subdoc, chapter 8)
      |- accusation.tex (subdoc, chapter 9)
|- images (folder)
   |- map-of-whereville.png (image)
   |- title-page-artwork.png (image)
|- storage (optional folder: backup files, etc.)

 

Main Document

TOP

The preamble and document body pages describe this in detail.

  • A typical main document looks like this, with any number of sub-documents:

    %!TeX program = lualatex
%!TeX encoding = UTF-8
\documentclass{novelette} % Preamble follows:
\title{Book Title}
\author{The Author}
% other preamble settings
\begin{document} % Document body follows:
\frontmatter
\subdoc{path/filexname.tex}
\subdoc{path/filename.tex}
\mainmatter
\subdoc{path/filename.tex}
\subdoc{path/filename.tex}
\backmatter
\subdoc{path/filename.tex}
\end{document} % Closes document body.

 

Sub-Documents

TOP

Full discussion: sub-documents.

  • A typical sub-document looks like this:

    %!TeX program = lualatex
%!TeX encoding = UTF-8
\def\thisdoc{M:PathFromMainDoc/ThisSubdoc.tex}
\input{PathFromSubdocTo/MainDocument.tex}
\begin{component}[option]
Content goes here.
\end{component}
\begin{component}[option]
More content.
\end{component}
\subdoc{path/filename.tex} % Path from main document.

 

Components

TOP

Full discussion: components.

All printable content must be contained within a component environment. Above, the example sub-document has two components of its own. It also includes a subdoc, which will introduce at least one more component.

Non-printing commands, such as \frontmatter, sit outside components.

 

Graphics

TOP

The full discussion of graphics is on another page. In general:

Novelette disallows vector drawings. No TiKz, no EPS, no including other PDF. All graphics must be png raster images, with certain specifications.

Why so restrictive? In user forums, print-on-demand authors often wail about print services rejecting their PDFs, due to graphics issues. This is not caused by TeX; it can happen with any software. Professionals have programs that post-process PDFs to remove those problems, but that requires graphics expertise (and expensive software). So, Novelette will not let you do anything that is likely to cause those issues.

 

File Paths

TOP

All file paths must follow these rules:

  • All paths are relative to the main document no matter which file calls another file.

  • Absolute paths, and symbolic links, are prohibited.

  • Paths and filenames may not contain spaces.

  • Paths and filenames may not contain the asciitilde (~) or backslash, and may not contain any character that is not universally accepted as valid by Linux, OS/X, and Windows 10+.

  • Paths and filenames may contain hyphen and underscore.

  • Paths and filenames may not contain commands, such as \chapterfolder/chapter-1.tex.

  • You cannot customize the path rules. There is no equivalent to LaTeX \graphicspath or similar settings.
