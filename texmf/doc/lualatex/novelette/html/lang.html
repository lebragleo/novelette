Novelette Documentation - Language

Overview   List of Codes   Language-Specific Notes

Overview

The \lang{code} setting chooses hyphenation patterns. It does not perform other language‑specific functions, such as time and date formats.

Novelette was developed for English. The inclusion of other languages should be considered experimental; the fonts have the necessary characters, and the hyphenation patterns are available in TeX. But neither babel nor polglossia is loaded. If you need more language‑related features, then you should use something other than Novelette.

 

List of Codes for \lang{code}

TOP

These codes are case-insensitive: en-US and en-us are the same.

  • en-US -> American English. Red is a "color".

  • en-UK -> British English. Red is a "colour". Also en-GB.

  • de    -> Post-1996 German (Germany, Austria).

  • de-CH -> Swiss German.

  • nn    -> Nowegian nynorsk.

  • no    -> Norwegian bokmal.

  • nb    -> Norwegian bokmal.

  • fr    -> French (any).

  • pt    -> Portuguese (any).

  • ca    -> Catalan.

  • eu    -> Basque.

  • es    -> Spanish (any).

  • it    -> Italian.

  • nl    -> Dutch (Netherlands).

  • sv    -> Swedish.

  • da    -> Danish.

  • fi    -> Finnish.

  • ga    -> Irish (modern).

  • cy    -> Welsh.

  • is    -> Icelandic.

  • gd    -> Scottish (modern).

  • la    -> Latin (modern).

 

Language-Specific Notes

TOP

If no \lang is specified, or if \lang{en} unmodified by US or UK, then a generic American English pattern is used. Better to specify en-US or en-UK.

  • German: Pre-1996 German (of Germany) is not available. If you type the eszett, you get it; but the word may be incorrectly hyphenated. The Novelette fonts use short-arm f, so that there is no issue with incorrect ligatures.

  • For French punctuation, which requires nonbreaking space before or after certain symbols: Use ~ (asciitilde) there. In Novelette, it is a reduced width nonbreaking space. Example: Zut~!

  • Portuguese: If you need to place a hyphen at the end of a line, and at the beginning of the following line, try this: \-- for the hyphen. That inserts a soft hyphen followed by an ordinary hyphen. Mid-line, only one of them prints.

  • Catalan: The ele geminada is available. You may type the actual middot character (not period) between two L. Use {\Lgem} or {\lgem} to print all three characters (two L with middot between). Works uppercase, lowercase, small caps. Although you may use the Ldot character, this is not best practice.

  • Dutch: {\IJacute} and {\ijacute} place the acute over both characters. This is the only method available in Novelette. If you try I\'J it will fail.

  • Finnish: Be sure that the characters you need are in the fonts.

  • Irish: The Tironian et (agus) is available. Use {\agus} for that. Only modern Irish is supported.

  • Latin: Only modern Latin is supported.

  • Hawai'ian: Hyphenation for this language is unavailable, but the necessary characters are in the fonts (vowels with macron, okina). Use {\okina} for that.
