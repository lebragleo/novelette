Overview

To use Novelette, you will need a only a small part of the enormous TeXlive software. You will need a program that can view PDF. If the book interior has images, you will need software for creating png images, and will probably need the ImageMagick program.

 

Required TeX Support

TOP

You need a working installation of TeX version 2024 or later. It must have:

  • Essential programs and files,

  • LaTeX fundamental packages,

  • LuaTeX packages,

  • US and UK English,

  • Your language package (if not English).

  • If your operating system is Windows, is must be Windows 10 or later. Not MinGW. If your book has any images (not including the cover), then you may need to use the Linux subsytem for processing image files.

That is not a lot! It occupies less than 200Mb on the developer's storage, which is less than 5% of all TeXlive. So if you are new to TeX, be sure to install only what you need.

Linux users may install TeX Live, or sometimes it can be installed from your Linux distribution. Prefer TeXLive, since some Linuz distros have out-of-date code.

Mac OS/X users can install MacTeX.

Windows 10+ users may try TeX Live or MiKTeX. But if you are familiar with the Linux subsystem and know how to configure it for GUI, do it on Linux. Support for MinGW/Msys is unknown.

If your operating system is Android, do not despair! Install the Termux app from F-Droid. It does not require root privilege. Install xfce4 and tigervnc into Termux. The RealVNC app can display results as GUI. Detailed configuration instructions are online. You may then install TeXlive into Termux, and reboot Termux when done. This is the setup used by the Novelette developer!

In addition to TeX, you will need a PDF reader (do not read PDF in a web browser). If possible, use a PDF reader that can dynamically update the display of an open file, if the content of the file changes. Evince, and some others, can do that, at least on Linux.

You may compile your documents from Terminal command line, or from the TeXworks GUI. TeXworks may be part of TeXlive, or you may need to install it separately. Do not use any other GUI, such as TeXshop or TeXstudio. Those other GUI programs are optimized for academic math, which is not what Novelette does.

If your book has interior images, you will need the ImageMagick command line program. Linux users can get it from their Linux distribution. Android/Termux users can get it from Termux. OS/X has it in bew. Windows users should install it into the Linux subsystem, if possible. Although ImageMagick is available for Windows, Novelette's shell scripts are not in the syntax used by Windows scripting host.

 

LuaLaTeX Test File

TOP

After satisfactory TeX installation, copy this code, and paste it into a plain text editor. Save the file as test.tex in your home directory:

%!TeX program = lualatex
%!TeX encoding = UTF-8
\documentclass{article}
\ifdefined\directlua\else\typeout{Wrong compiler!}\fi
\RequirePackage{luahyphenrules}
\HyphenRules{british}
\begin{document}
Hello, World.\par
Look for the year in this banner:\par
\luatexbanner\par
It must be 2024 or later. If not, bad news.\par
\end{document}

Then compile it. If you are using a GUI (such as TeXworks), simply open the file there, and process it. The top two lines, beginning with %!, are "magic comments" that tell the GUI what to do. But if you are compiling via command line:

lualatex test

If your TeX installation is new, its internal housekeeping will cause some delay, while it generates formats, locates fonts, and so forth. This only happens once.

When that succeeds, a PDF is produced. Open it in a PDF reader. Be sure to check the year in the banner. If it is not 2024 or later, your TeXlive is too old. If you cannot compile the test file, be sure that you correctly copied the test code, and that you are launching TeX from the directory where you placed that file.

If you cannot make that work, then you cannot install Novelette.

 

Installing Novelette

TOP

If Novelette can be installed from TeXlive, do it that way. Its package name will be novelette. But to avoid possible confusion, be sure that its documentation is (essentially) what you see now.

However, there are no immediate plans to upload Novelette to CTAN (where TeXlive gets its stuff). It may never happen. In that case, you must manually install the files. Here's how:

Your TeX setup has a folder known to TeX as TEXMFHOME. Its actual name is usually something else. To find it, run this shell command:

kpsewhich -var-value=TEXMFHOME

Sometimes that folder does not yet exist, or it may be hidden. It it does not exist, create it. All of Novelette will be placed into that folder.

Get the Novelette code from its project page at GitHub. Enter the Novelette texmf folder, and copy everything (with its folder structure) into your TEXMFHOME. Do not copy anything that is not within the texmf folder.

So if TEXMFHOME happens to be /home/.texmf, then you now have file /home/.texmf/tex/lualatex/novelette/novelette.cls and all the other files living in their proper places.

That's all you need to do. The next time you run TeX, it will automatically find Novelette. There will be a short delay while it incorporates the new files into its system.

If you have multiple devices with different user names, and different locations for TEXMFHOME, no problem. You can move your writing from place to place, because your own files do not know or care where TeX and Novelette reside.

If, at some future time, Novelette becomes part of TeXlive, then your installation in TEXMFHOME will over-ride anything installed by the TeX package manager. You will have to decide whether to remove Novelette from TEXMFHOME, or not.

 

Novelette Test File

TOP

Novelette has a built-in test file. From your home folder or desktop (not anywhere within Novelette's folders) command:

lualatex novelette-test

It may take a moment, while TeX locates the Novelette files and initializes its fonts. After the first time, that delay will not be repeated.

The PDF is two pages long, even though its content is only one page. Novelette ensures that each PDF has an even number of pages, and that the final page is entirely blank. This feature can be disabled for individual documents.

If that did not work... You are out of luck. The most likely problem is that you have multiple TeX installations that conflict with each other, or you changed the path to the TEXMFHOME folder.
