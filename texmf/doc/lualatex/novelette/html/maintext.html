Main Text

Overview  

Overview

Every component environment starts with a display zone. The zone may be empty, or occupy the entire component, or anywhere in between.

In most cases, such as new chapters, you end the zone somewhere in the middle of the component's first page.

Do not confuse main text with main matter. Main text, discussed on this page, is within a component, no matter where it appears in the book. Main matter is the portion of the book located after front matter, and perhaps before back mattr.

 

Command: \maintext

TOP

The \maintext command ends the display zone. Then:

  • One or two blank lines are automatically inserted above \maintext.

  • The display content is usually off‑grid, due to style scaling. Novelette applies whatever vertical space is needed, to restore the following text to grid.

  • \styleN commands are no longer available.

  • A block environment may not use small text.

  • Except in front matter and back matter, images may float.

  • The \init, \dcap, \scene, and \sceneimage commands are available.

 

Guide Marker

TOP

If you use a guide marker (recommended):

  • The first line of main text is not forced to align with the guide. Whether or not it aligns, is your decision; Novelette does not care.

  • Within the display zone, use \blankline or \vspace to adjust its height.

    Measure \vspace with units of \baselineskip, not pt, like this:

    Good: \vspace{2.3\baselineskip}. Bad: \vspace{10pt}.

  • Outside of display zones, you may use \blankline but not \vspace or \vskip.

 

Initial Letter: \init

TOP

When main text is the start of a chapter, most book designs apply a special style to its first letter. The most common design is to enlarge the letter, so that it sits on the normal first baseline, and rises above normal text. This is distinctive, without disrupting the following lines. Novelette has a command for this purpose:

\init{letter}[more text]

This command may only be used at the very start of main text, immediately after the \maintext command. If you place anything (even (\blankline) between \maintext and the \init or \dcap, then the code will fail.

\init{letter}[more]

  • This command may only be used immediately following \maintext. If any text or command is between \maintext and \init, then \init will fail.

  • Code such as \'E is treated as a single letter.

  • If the text begins with quotation marks, guillemets, or Spanish inverted marks, place them within the command, along with the first letter. The punctuation will be automatically adjusted for best appearance.

  • Except for Dutch IJ, avoid using more than one letter. But Novelette does not enforce this rule.

  • If the initial letter is a word in itself (such as English I), put the space within the braces, next to the letter.

  • [more text] prints its text with lowercase letters in small caps. This is desirable. The text should be only a few letters or words. It cannot extend all the way to the right margin. Example:

    \init{W}[hen they left,] the room was silent. ... etc.

    In the above example, note that I is not repeated in small caps, because it is already printed as the initial letter.

    If the initial letter is followed by a left bracket, it means the start of more text with small caps. But if that is not what you mean (unlikely), use \[ there, which prints the ordinary left bracket, and does not signal more text.

  • \init automatically kerns the initial letter, so that there is not a large gap to whatever follows. If that too narrow for you, the starred \init* kerns a little looser.

Example:

\init{T}[hey were lost.] Sadly, they had no pizza. ... etc.

Drop Cap: \dcap

TOP

Instead of \init, you may use a drop cap for the first letter of main text. This is an enlarged letter occupying the first two lines, with other text wrapped around it.

Popular fiction almost never uses drop caps. They only look good when the opening paragraphs have enough lines to surround them, without excessive white space. But popular fiction usually has short paragraphs (sometimes one line), dialog with punctuation, and other text that interferes with good-looking drop caps. Prefer \init.

\dcap{letter}

  • This command may only be used immediately following \maintext. If any text or command is between \maintext and \init, then \dcap will fail.

  • Code such as \'E is treated as a single letter.

  • Do not place punctuation. If necessary, re-write your text, so that the sentence does not begin with quotation marks, guillemets, or Spanish inverted marks. Or, omit the marks there. If you cannot do that consistently, then avoid drop caps.

  • The drop cap occupies two lines. No more, no less.

  • The top of the letter (without diacritical) is at the top of normal uppercase in the first line. The baseline of the letter is at the baseline of the second normal line.

  • If a diacritical is above the letter, it will appear higher.

  • Letters J, Q, and Ccedilla are specially shaped to fit.

  • Unstarred \dcap kerns the immediately following letter. It is slightly closer to the drop cap, compared to the second line.

    Starred \dcap* does not kern the immediately following letter. It is vertically aligned with the second line. This is appropriate when the drop cap is a one-letter word, although you may use it always, if your prefer the appearance.

  • If the first paragraph occupies only one line, do not end it with \par. Use \fakepar instead.

Example 1:

\dcap{O}n the next day, all hell broke loose. An overnight storm had severed the power lines, dropping wires all over the roads. Nobody was sure whether they were live. To make matters worse, pizza delivery was at a standstill.\par

Scenes

TOP

Most chapters have some kind of scene break. The break may vary from barely noticeable (only a blank line), to more prominent methods.

  • In general, use \blankline one or more times, to separate scenes. Do not use \null.

    If the blank line happens to fall at the last or first line of a page, use \dinkus there. Yes, that is its name in typography. It prints three spaced asterisks, so that the gap is more noticeable.

  • You may also use \dinkus as the standard scene separator.

  • \scene{text} prints its text with slightly different style than normal main text. The difference is enough to notice, but not enough to be distracting.

    Blank lines are inserted above and below the scene text, to occupy a total of 3 lines. However, if the scene break occurs at the top of a page, the upper blank is omitted.

    The width of the scene text is limited, to less than one full line.

  • \sceneimage{PathTo/filename.png} places a specially-formatted image. See the graphics page for details.

    This method is especially well-suited for chapters (or long stories) that consist of distinct episodes.

    Or, you may use an ordinary \image.

  • The \scenestyle setting (in preamble) determines how \scene and \sceneimage are horizontally aligned. Default center. There are no local options.

  • For larger scene gaps, add \blankine above and/or below.

  • When you use \blankline, \dinkus, or \sceneimage, the following paragraph is not indented. This is automatic.

    If you use an ordinary \image, then you must write \noindent at the start of the next paragraph.

  • Scenes are not numbered automatically. If your scenes need numbers, use the placeholder \next command, until you know their numbers.
