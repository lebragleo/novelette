Table of Contents

Overview  

Overview

Most popular fiction has no table of contents. The reader is expected to read through, perhaps placing a bookmark (or face the open book down) as a pause.

A table of contents is used when the book (1) Is a collection of short stories, or (2) Has titled chapter so distinctive that they are self-contained episodes.

Novelette has no automated table of contents, because that requires two-pass compiling (not the Novelette way of doing things). If you need a table, you must construct it yourself. This shows you how to do it.

The Table is a Component

As with all other content, a table is contained in a component environment. Use the [recto] component option, to ensure that the table begins on a recto page.

When you do not yet know page numbers (and perhaps do noy know chapter numbers), use the {\next} command. This prints a pair of numbersigns (##). The presence of any {\next} forces draft mode. The Summary will remind you.

To proceed with preview or final mode, you must manually remove each {\next}, and substitute the actual value. The means you must be near finishing your work.

Table Design

Novelette does not care how your table looks. For simplicity, a few commands will help your design:

  • Enclose the table in a block environment. Choose the side offsets so that the entries are not too wide, not too narrow.

  • Use \styleN (N=1,2,3,4) for the table title.

    The title may be as simple as Contents. In some cases, the title may repeat the book title. For example, if your book is The February County with a dozen short stories about snow, you might use The February County instead of Contents

  • Command \entrygap{number} may appear before the table entries. The number is 0 to 1. Default 0.

  • \entry{number}{name}{page}

      • Sample Table

      \begin{component[recto] \blankline \begin{block}[3+3] \style3[scale=1.5]{The February County} \entrygap(0.2} \entry{1}{Wicked Flakes}{\next} \entry{2}{Yellow Snow}{\next} \entry{3}{Snowman's Surprise}{\next} \entry{4}{When Hell Freezes Over}{\next} \entry{5}{School's Out}{\next} \entry{6}{Slithering Sleet}{\next} \end{block} \end{component}
