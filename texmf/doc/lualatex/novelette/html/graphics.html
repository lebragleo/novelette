Overview

If your book has any graphics, be sure to read this page! Novelette does not use any of the standard LaTeX methods for graphics. In particular, the \includegraphics command is disabled.

Novelette is intended for popular fiction, such as mystery novels, where the use of images is very rare. If your story requires many images, then use something other than Novelette.

Novelette cannot create the book cover. For that, you need other software. But there is some useful information about covers lower on this page.

 

Graphics Format: png

The png (portable network graphics) raster image is the only format supported by Novelette. No exceptions. You cannot create TiKz drawings. You cannot include eps or pdf files.

  • Novelette does not have \caption or anything similar, and cannot draw a frame. If you need these, you must design them into the graphics file.

  • Internally, each file must state its resolution (density). This is normal for graphics design software.

    Note: Resolution is usually described terms of pixels per inch. The png internal format convert it to pixels per centimeter. This is automatic; have no fear.

  • Graphics color space must be either monochrome (black/white at 1‑bit per pixel), or single-channel grayscale (8‑bits per pixel).

  • Preview and final modes require that the files pass validation tests.

  • In most cases, files that do not meet all of the above requirements can be easily repaired using utility scripts that come with Novelette.

  • The file will print at its exact size, without rescale or other transform. Thus, a file that is 150x450 pixels at 300px/inch, will print at 0.5x1.5 inches.

  • Best Practice: Design graphics for print‑on‑demand.

    • A monochrome file (1‑bit per pixel) should use 600 pixels/inch resolution, or greater (if your print service allows it).

    • A grayscale file should use 300 pixels/inch. There is no advantage to using a higher value, although some print services prefer a slightly higher value.

    • The technology does a poor job with smooth gradients, and a poor job for grays that are close to white or black. When you process your files using Novelette's utility scripts, grays close to white are forced to white, and grays close to black are forced to black.

    • If possible, test your files by printing them with inkjet, and also by printing them with toner (like photocopier, but can read digital files). Be sure that only black ink is used!

 

Path and Filename

Have you ever archived or copied a work containing many files, only to discover that something is missing? Novelette feels your pain. For that reason, you must follow these rules:

  • File names must have the lowercase .png file extension.

  • File paths are always relative to the main document, even if the files are called by a sub-document.

  • The names and paths may not contain spaces, or any character that is not a valid path/file name in all modern operating systems. No backslash! You may use hyphen or underscore.

  • No absolute paths: No Linux /home/john/. No Windows C://john. No asciitilde ~.

  • No symlinks (softlinks).

  • Files must be located in the same folder as the main document, or in a subfolder (maximum 5 levels) down from the main document.

  • You cannot use \graphicspath to change anything.

  • Best Practice: Within the main document folder, create another folder for storing native-format graphics files. Then, if you ever need to edit them, you have the originals where they can easily be found.

Image Dimensions

This applies to ordinary images, using the \image command.

  • Run a test document with your Preamble settings, in draft mode. The Terminal Summary will show the textwidth, font em size, and baselineskip. These are specific to your settings. If you change anything in Preamble, then the values will change.

  • The maximum width of an image depends only on the textwidth. For example, if the textwidth is 4.2in, a grayscale image at 300px/in cannot exceed 4.2*300 = 1260px width.

  • The maximum height of an image depends on font em size, baselineskip, and number of text lines that the image will displace. The number of lines is declared as option for the \image command.

  • EQUATION for calculating the maximum height of an image: P is its maximum height in pixels, L is the declared number of lines, em and baselineskip are measured in pt, and R is the image resolution in pixels/inch:

    P = R*[0.84*em + (L-1)*baselineskip] / 72.27

    For example, if R=300px/in, L=5, em=11.7pt, and baselineskip=14.8pt:

    Max height = 300*[0.84*11.7+(5-1)*14.8]/72.27 = 286 pixels.

    The actual calculation is a little more than 286, but the value must be truncated down to an integer value. Never rounded up.

  • Or, if you already know the pixel height, you may calculate the minimum number of lines required:

    L = 1 + [(72.27*P/R) - .84*em] / baselineskip

    Round L up (never down) to nearest integer.

  • Unsure of the book trim size, or other Preamble settings? If you design images so that they do not exceed 3.4in width and 3.4in height, then they will fit all sizes provided by Novelette, although the number of displaced lines will vary.

    That height allows for at least 7 lines of text on the same page as an image. Better results will be obtained if you first decide on trim size and layout, then decide on the displacement for each image, then design the images.

  • When an image is at or near its maximum height, the above and below clearance to text will be adequate, but not very great.

The \image Command (Also \image*)

Usage: \image[option]{PathTo/filename.png}

There are two possible formats for the option: If it contains the keyword scene, then see the next section. When it does not contain scene, use this format:

Option: [lines=L,align=A,float=F,tweak=T].

  • L is an integer 1<L<(lines per page).

    Although it is written as an option, each image must declare its number of lines. This is the amount of vertical space that the image will use.

    If the image does not fit in its reserved space, it is a problem. It will not be printed somewhere else. Instead, a gray placeholder rectangle prints where the image should print, occupying the reserved amount of vertical space.

    If the image is shorter than its reserved space, it will be automatically padded to occupy the full space.

  • A is one of left right center.

    Horizontal alignment. Default center.

  • F is one of none here top bottom.

    In frontmatter, backmatter, and component display areas, only none permitted; it is the default.

    In main text, the default is here. Novelette automatically uses top as fallback for here.

    There are no page floats. If you need an image on a page by itself, use a component environment with [single] option. Then the image can (if desired) occupy the full textblock. This should never be done in the middle of a chapter, where it would break the text flow.

  • T is one of up down mid.

    When the height of an image is less than its maximum (for any particular lines=L), it will be padded above and/or below. Tweak changes where padding is applied. Choice up moves the image as high as it can go (all padding beneath). Choice down moves the image as low as it can go (all padding above). Choice mid is the default, which splits the padding.

    Tweak does not change where an image floats, and does not change the number of displaced lines.

Mandatory: {PathTo/filename.png}

  • In draft mode, unstarred \image does not look for an image file. It prints a placeholder, whether or not the file exists. You may use empty braces, or write a short note, such as {Map of Whereville}, as a reminder to yourself.

    If you write a reminder, do not use macros such as \textit or \smcp. Do not use diacritical codes such as \'E for Eacute. The reminder will print as a label, within the placeholder area (no more than final 32 characters).

  • In draft mode, starred \image* looks for its image file. If the file exists in an allowed folder, has png file extension, and fits in its reserved area, then it prints. Otherwise, error, and a placeholder prints. In any case, the image is not inspected for specifications; an off-spec image (such as color, or gray with transparency) prints without error or warning.

  • In preview and final modes, \image and \image* are the same. The file must exist in an allowed folder, fit its reserved area, and meet all print-ready specifications. Otherwise, error, and a placeholder prints.

  • Image placeholders occupy the correct number of lines, and have the correct float, alignment, and tweak. But since the height and width of the real image is unknown, the placeholder size is guessed at slightly smaller than the maximum possible size.

 

Using an Image as Scene Break

When \image has the single option [scene], it is specially formatted for use as a scene break. This is one of several ways to separate scenes within a chapter or long story.

Typically, the image will be rasterized text in a prominent font. Intead of black, it will be some shade of gray, so that it is not too prominent. The font does not need to be one of the Novelette fonts, as long as its license permits commercial usage.

  • Option [scene] cannot be combined with other options.

  • The image does not float.

  • Horizontal alignment is the \scenestyle setting, or default center.

  • Maximum image width is 3.4in, which is more than any good-looking scene break needs. Maximum image height is 0.24in. These apply regardless of trim size or layout.

  • The image is automatically padded to occupy a total of 3 lines. If you wish, use \blankline above and/or below.

  • The following paragraph is not indented.

Shell Scripts

In its documentation utilities folder, Novelette provides several shell scripts. These are coded for Linux or Linux-compatible shells (including Mac OS/X and Android/Termux). If you are on Windows, use the Linux subsystem.

These scripts will take off-spec image files, and convert them to on-spec. You will probably need to do this for preview and final modes. Instructions are in utilities.

The scripts require ImageMagick, which can be installed via your Linux distribution.
