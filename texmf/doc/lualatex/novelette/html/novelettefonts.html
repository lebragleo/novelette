Overview

Novelette comes with its own fonts They are custom‑designed for the purpose of print‑on‑demand popular fiction, and have properties that are known to Novelette. You may not add any other fonts, but you may use other software to create png images with text in any font allowed by its license.

All of the Novelette fonts, by Terry Lebragleo, carry the SIL Open Font License. They are free for commercial use. If someone else creates fonts with base name Novelette, they are unrelated, and may have a different license.

Although you may use these fonts in a word processor or other LaTeX document class, that is not a good idea, because you will not have the benefit of font-Novelette interaction.

Fonts are always subset-embedded in your PDF.

Main (Normal) Font Size and Baseline Skip

  • Main font size is calculated from \trimsize and \layout. You do not directly choose the font size or baseline skip.

    • The largest main font size is 12.05pt (12 PostScript points), typical for large trimsize.

    • The smallest main font size is 10.7pt (10.66 PostScript points), for small trimsize and congested layout.

    • For medium-size books (5.5in x 8.5in, or Demy 135mm x 216mm), using header or footer (but not both), main font size is typically 11.7pt (11.66 PostScript points). It can vary ±3% from that, depending on settings.

  • Calculated baseline skip is never less than 1.2x the calculated font size. It will be more, when your trimsize is large, or there are few lines per page.

NoveletteSerif12

  • NoveletteSerif12 is the only font that is used in ordinary text. This book‑weight font is designed for relaxed, continuous reading. It has Regular and Italic shapes, but not Bold or BoldItalic.

  • It is vaguely in the same class as Garamond or Bembo, but is not a clone or historical reproduction of any font.

  • It may also be used in page headers, block environments, and display zones.

  • The Regular shape includes small caps, oldstyle and lining numerals, and some special‑purpose characters.

  • The Italic shape has oldstyle and lining numerals, but not small caps.

  • Depending on trim size and layout, this font is set in the range 10.7 to 12.05pt.

NoveletteSerif10

  • NoveletteSerif10 is automatically substituted for NoveletteSerif12, in footnotes and in blocks with small text. You cannot select it manually.

  • Except for some special characters, the character set and features are identical to NoveletteSerif12, for the Regular and Italic shapes.

  • This font is very slightly heavier than NoveletteSerif12, but it looks correct at its smaller size, which is 87.5% main font size. That is comparable to using 10.5pt for small text, when main text is 12pt.

  • At the smallest font size, this font is set to 9.1pt. Its readability should be comparable to fonts such as Aptos, Calibri, or Times New Roman at 8.1pt, or Adobe Garamond Pro at 9.5pt.

NoveletteSans and NoveletteDeco Fonts

  • These are several fonts, which may be used for decorative purposes, only in certain locations.

  • Font samples:

  • There are no Italics, although some of the fonts are naturally slanted. Numerals are always lining. Many of these fonts do not have lowercase letters (if you type lowercase, you see uppercase).

  • These fonts may be used in page header/footer, the \name and \subname commands. They may not be used anywhere else.

  • If you need different decorative fonts, you cannot use them in Novelette. But you can create png raster images, using any fonts that are licensed for your purpose.

  • The Sans fonts are original designs. The Deco fonts are modified from fonts designed by others, using the Open Font License.

  • These fonts do not contain characters, even in ASCII and Latin-1, that would not normally be used in places such as chapter titles and page headers.
