Overview  

Overview

This page describes commands and environments that can change the font, position, and size of text. The various styles cannot be used everywhere; most of them are specific to document location (front/main/back matter), or to inside/outside a display zone.

Standard LaTeX commands, such as \large and \raggedright, do not work in Novelette. Instead, you must use Novelette's own commands and options. This provides a consistent interaction between the code and the fonts.

Remember that Novelette is for printed, popular fiction. If the Novelette styles cannot do what you want, then either use some other document class, or reduce what you want to what you need.

\name[option]{text}, \subname[option]{text}

These commands apply a variety of styles to a line of text. They are typically used for such purposes as chapter titles and subtitles.

  • They may only be used within a display zone, but not within a block environment.

  • They may not be nested.

  • They have no particular meaning or hierarchy. All they do is style text.

  • You may repeat \name and \subname in any order, in any display zone.

  • The styled text must fit on one line, without wrap.

  • The global default options are set in preamble by \namestyle and \subnamestyle. The local options for \name and \subname use the same syntax, but only apply per-instance.

Inital Letter of Main Text

When main text is the start of a chapter, most book designs apply a special style to its first letter. Novelette has \init{letter} for that purpose. It styles its letter with the main font, but at double the normal size. The baseline is the same as normal baseline, so the top of letter rises above the other text on the first line.

This command may only be used at the very start of main text, immediately after the \maintext command. If you place anything (even (\blankline) between \maintext and the \init or \dcap, then the code will fail.

\init{letter} usage:

  • Code such as \'E is treated as a single letter.

  • If the text begins with quotation marks, guillemets, or Spanish inverted marks, place them within the command, along with the first letter. The punctuation will be automatically adjusted for best appearance.

  • Avoid using more than one letter. But Novelette does not enforce this rule.

  • Do not put a space after this command, unless the initial letter is a word.

  • Often, the next few letters (whole words) look best with small caps:

    \init{I}\smcp{t was dark.} The heavy gloom...

    In the above example, note that I is not repeated in small caps, because it is already printed as the initial letter.

Drop Cap

Instead of \init, you may use a drop cap for the first letter of main text. This is an enlarged letter occupying the first two lines, with other text wrapped around it.

Popular fiction almost never uses drop caps. They only look good when the opening paragraphs have enough lines to surround them, without excessive white space. But popular fiction usually has short paragraphs (sometimes one line), dialog with punctuation, and other text that interferes with good-looking drop caps.

If you use \dcap, it must immediately follow \maintext. But you should use \init instead. Most actual books do it this way. But if you are determined to use drop caps, here is how:

\dcap{letter}, \dcap*{letter}

  • This prints the letter as a "drop cap".

  • Do not place punctuation. If necessary, re-write your text, so that the sentence does not begin with quotation marks, guillemets, or Spanish inverted marks. Or, omit the marks there. If you cannot do that consistently, then avoid drop caps.

  • Code such as \'E is treated as a single letter.

  • The drop cap occupies two lines. No more, no less.

  • The top of the letter (without diacritical) is at the top of normal uppercase in the first line. The baseline of the letter is at the baseline of the second normal line.

  • If a diacritical above the letter, it will appear higher.

  • Letters J, Q, and Ccedilla are specially shaped to fit.

  • Unstarred \dcap spaces both lines equally (they vertically align) whether or not the drop cap is a one-letter word. Starred \dcap* affects the first line; it brings the immediately following text closer to the drop cap. But if the drop cap is a one-letter word, a space restores vertical alignment.

  • If the first paragraph occupies only one line, do not end it with \par. Use \fakepar instead.

Block Environment

The block environment can do many things. It can set the left/right offsets of the block, measured as multiples of normal paragraph indent (1em). Alternatively, it can measure the width of a previously-defined line of text, then calculate the offsets for best appearance of that width. It can set the justification of text within the block. It can set whether paragraphs within the block are indented, or not. And, if the block is within a display zone, it can reduce the font size and lineskip of its text.

Use the block environment for block quotes, epigraphs, poetry (verse), and other places where a block of text needs special treatment. If you need centered text, put it in a block, because Novelette disables the center environment and \centering command.

\begin{block}[option]

contents

\end{block}

    You may not use block inside other styling commands. The parent element of block must be the component environment, before or after \maintext.

  • You may not use block in a legal component, or in footnotes.

  • You may not

    nest one block within another. If you need that effect, end one block before beginning a new block.

Block Option

Read this carefully:

\blockline{text}

This command is needed when a subsequent block has option s/0 or s/s. The text is always in the main font.

  • The text may be styled with Italics, small caps, oldstyle.

  • The parent element of \blockline must be a component environment, before or after \maintext.

  • The width of text is measured, when needed by a following block. It may be normal size, or small, depending on the block option.

  • Only the width is used for calculations. The text is not printed. It may or may not appear in any block.

  • The width may not exceed the textblock width, less two normal paragraph indents. It may not wrap.

  • The measurement is made without paragraph indent. If you need it to be measured with indent, write \blockline{\indent text}.

  • The width of text is a global value that remains in effect, until changed by a subsequent \blockline.

Scenes

In general, use \blankline one or more times, to separate scenes. Do not use \null.

If the blank line happens to fall at the last or first line of a page, use \dinkus instead. Yes, that is its name in typography. It prints three spaced asterisks, so that the gap is more noticeable.

You may use an \image between scenes. Trick: If the image is prominent (perhaps using bold or heavy text), make it medium grayscale instead of monochrome. That prints a nice balance: distinctive, but not overly distracting.

Novelette provides the \scene{text} command. The text must fit on one line, and not exceed the textblock width, less two normal paragraph indents. The appearance of this text is set by \scenestyle in preamble. There are no local options, but you may place a \blankline above and/or below.

Scenes are not numbered automatically. If your scenes need numbers, use the placeholder \next command, until you know their numbers.
