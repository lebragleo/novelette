Overview

The trim size is the physical width and height of book interior pages, regardless of what those pages contain. Page layout refers to general appearance of most pages, particularly the number of lines in the main textblock, and whether space is reserved at top and bottom for header and footer.

Unlike other LaTeX document classes, Novelette does not allow you to set margins, font size, or line separation. These are automatically calculated, based on trim size and layout. The values are those that fit well for print-on-demand popular fiction, according to the requirements of most services.

All values have defaults, which may be determined by other defaults and settings. If in doubt, allow the defaults.

^TOP

Trim Size: \trimsize{width=W,height=H}

This command is used at most once, in Preamble. Values W and H are lengths, which must have units of either in (inches) or mm (millimeters). Default is width=5.5in,height=8.5in, a frequent choice in the USA.

If you set one of width or height, then you must also set the other. The same units must be used for both.

Novelette limits the size. Height must always exceed width by a certain amount. The smallest dimensions will accomodate US 5x7 or British B-format. The largest dimensions will accomodate US 6x9 or British Royal. Width may range from 5in to 6in. Height may range from 7.7in to 9in. The most attractive layouts will be in the middle, US 5.5x8.5 or British Demy.

Note that the small "mass market" size cannot be used in Novelette. Large textbook and business sizes cannot be used.

When selecting a trim size, be sure to choose one of the standards (lower cost). Also be sure to choose off‑white paper, usually called cream or creme. Never choose white for popular fiction.

The distributor may ask whether you want "extended distribution" or something similar. Don't do it. That allows booksellers to stock copies without payment unless they are sold. When they do not sell, the copies are shredded, and you pay the cost.

If your book will be printed in more than one trim size, each size is treated as a separate book, with its own ISBN code.

\layout{lines=L,pagestyle=P,glue=G,cpl=C}

This command may be used only once, in Preamble. You may set all of the values, or only some of them. Anything you do not set, will retain its default value.

^TOP

lines=L

This sets the integer number of lines per page, in the main textblock of running text. It does not count header or footer.

  • Minimum 26, maximum 35. Default 35.

^TOP

pagestyle=P

This sets whether or not pages have a header, a footer, or both. The content of headers may not exceed one line. No line is drawn beneath headers.

  • There will be some pages in the book that do not print the header or footer, but the areas for header and footer are still reserved.

  • Other commands are used for setting text in page headers, the font style of the text and numbers, and the page number decoration.

  • Choices for P are: marcen plain split center margin.

    • pagestyle=marcen is the default. It provides header, no footer. Page number is at outside margin. Decoration, if used, appears near page number. Text of header is centered.


      textblock below header

    • pagestyle=plain provides footer, no header. Page number is centered in the footer. Decoration, if used, appears on both sides of page number.

      textblock above footer

    • pagestyle=split provides header and footer. Centered text in header. Centered page number in footer. Decoration, if used, appears on both sides of page number

      textblock between header and footer

    • pagestyle=center provides header, no footer. Text, decoration (if used), and page number are centered in the header. Page number closest to outside. Note: If no decoration, a slash will separate text from page number.


      textblock below header

    • pagestyle=margin provides header, no footer. Page number at outside margin, decoration (if used), text of header. Mirrored verso/recto.


      textblock below header

^TOP

glue=G

The glue strip is the extra margin at the spine. This is where glue will be applied during binding, so this area is not visible to the reader.

  • glue=normal is default. It sets glue width at 0.125in (3.2mm), suitable for books that do not exceed some page count, usually 300, specified by the printer.

  • glue=wide sets glue width 50% wider than normal. This is needed for books with large page count.

  • Novelette does not automatically adjust normal/wide. You must do it yourself.

^TOP

cpl=C

Various studies suggest that popular fiction is most easily read, when the line width, and number of characters per line, are within certain ranges. Novelette calculates the ine width and font size, so that they sit in this range.

You may slightly adjust the average number of characters per line. This is only an estimate, because the number will vary from line to line. If you have a lot to say, or your language requires many long words, you may benefit from a larger number. If you have little to say, and your language has many short words, you may benefit from a smaller number.

  • Default cpl=66 is optimized for ordinary English. It is likely to be useful for other Western Euopean languages.

  • Range of cpl=C allows 52 <= C <= 72. May be decimal.

  • If in doubt, allow the default.

Layout Combinations

Novelette can produce your book with any combination of the layout settings, at any trim size within its allowed size range.

Some combinations look better than others:

The "small" sizes 5in x 8in, 129mm x 198mm (B-format), will look best when the layout does not use pagestyle=split, when lines=33 or less, and when cpl does not exceed 68.

The "large" sizes 6in x 9in, 156mm x 234mm (Royal) will look best when pagestyle=split, lines=35.

The "medium" sizes 5.5in x 8.5in, 135mm x 216mm (Demy) are best.

^TOP

No Settings for Margins, Main Font, or Font Size

Surprise! You cannot set the margins. You cannot choose the main font (for normal text). You cannot set the font point size, or baseline skip (line‑to‑line space).

Novelette requires you to use its own fonts. The point size, baseline skip, and margins are calculated from your \trimsize and \layout settings. The values are optimized for readability in popular fiction, within the constraints imposed by print‑on‑demand.

Why not allow you to over-ride Novelette's calculations? It is unlikely that you would manually select better values. Write your story!
