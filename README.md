# novelette
LuaLaTeX document class for printed popular fiction

This material is currently in pre-release version 0.1. Do not use for production.

While you are waiting...

TeXlive already has a "novel" document class, by a different programmer.
Its documentation says that it should be regarded as obsolete.
This project attempts to address the same user base:
writers of original fiction, such as murder mysteries, for print to paper
(not Ebook). But it is very different.

Novelette will be structured for English text, and most other Western European languages.
It will not aspire to greater language support.

Its configuration is almost menu-driven, with a limited number of choices that do
what you need, not necessarily what you want.

If you are looking for a document class that does more than others, then Novelette
is not for you. It does less!

It comes with its own fonts, optimized for close agreement with the LuaLaTeX code.

Be patient... The developer has much more material (including documentation) that
has not yet been uploaded.
